🎓 University Architecture & Concurrency Model

This web simulator demonstrates the identical concurrent business logic implemented in our pure Java desktop application:

Module 1: Product & Inventory

Encapsulated in Product.java & ProductRepository.java. Formatted in Indian Rupees (₹) using BigDecimal.

Module 2: Multithreading

Concurrent shoppers implemented via Customer.java (Runnable) and CountDownLatch synchronization barrier.

Module 3: Synchronized Inventory

Thread-safe monitor in Inventory.java throwing custom OutOfStockException to prevent negative stock.

Module 4 & 5: Discounts & Analytics

Polymorphic Strategy pattern (DiscountStrategy) and collection auditing using explicit Iterator traversal.
